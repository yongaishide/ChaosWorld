# ChaosWorld

Minecraft 1.21.1 整合包: KubeJS 魔改 + 多模组配置

## 目录结构

- `config/` — 模组配置
- `defaultconfigs/` — 默认配置
- `kubejs/` — KubeJS 脚本与数据(配方修改、任务等)
- `mods/` — 模组文件
- `resourcepacks/` — 资源包
- `ldlib2/` — LD Lib 配置
- `patchouli_books/` — 帕秋莉手册
- `Chaos_world.json` — NeoForge 版本清单 (MC 1.21.1 / NeoForge 4.0.43)
- `options.txt` — 游戏设置与按键绑定
