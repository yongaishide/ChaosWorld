# 第一次进入游戏

装好整合包、第一次进世界时，按这个顺序走一遍就不会迷路。

## 1. 先打开任务书

任务书（FTB Quests）就在背包/物品栏的默认位置，按快捷键即可打开。它是整合包唯一的官方引导，**不要跳过**：

- 第一章「开始」只有 4 个任务，会直接告诉你整合包的玩法框架，并让你领取**死亡不掉落**之类的开局奖励。
- 任务里会提示你打开帕秋莉手册《ChaosWorld 指南》（`chaosworld_books`），这本书目前还在补充中，内容不全时以任务书为准。

::: tip 任务书里的奖励
很多任务是「点击领取」型的，奖励包括 AE 频道数、死亡不掉落、抽奖、商店命令等。**记得手动领取**，默认不会自动发放（`default_autoclaim_rewards: "disabled"`）。
:::

## 2. 建议先改的几件事

| 设置 | 位置 | 建议 |
| --- | --- | --- |
| 内存 | 启动器 → 实例设置 | 6–12 GB，机器多 / 开光影就往上加 |
| Java | 启动器 → 实例设置 | 使用 Java 21+，不要用 Java 8/17 |
| 光影 | 视频设置 → 光影包 | 已内置 Complementary Reimagined + Euphoria Patches；配置不够就选不带 Euphoria 的版本 |
| JEI 界面 | 按 `E` 打开物品栏 | 已装 JEI，查配方全靠它；作弊模式默认关闭，可在 JEI 设置里自行开启 |
| 小地图 / 地图 | —— | 整合包内**没有**旅行地图类模组；FTB Chunks 自带地图界面，找结构用 Nature's Compass、Structure Compass |
| 中文汉化 | 语言设置 | 已内置汉化资源包（`Minecraft-Mod-Language-Modpack-Converted-1.21.1.zip`），确保它在资源包列表中启用 |

## 3. 性能相关

整合包内置了完整的优化组合，如果你还是卡：

- **Sodium + Sodium Extra + Iris**：渲染优化与光影，默认已启用。
- **ModernFix / FerriteCore / ImmediatelyFast / EntityCulling / lithium / cullleaves / accelerated-decay**：内存与帧率优化，不要关。
- **Clumps**：合并经验球掉落，减少卡顿。
- 机器大量堆叠卡顿时，优先关光影，其次降低模拟距离。
- 如果使用 `jdttimeaccelerators`（时间加速器）等加速设备，注意它会让附近机器一起加速，掉帧是正常现象。

## 4. 常用的几个快捷键

| 功能 | 默认按键 | 来源模组 |
| --- | --- | --- |
| 查配方 / 看用途 | 鼠标指向物品时按 `R` / `U` | JEI |
| 连锁挖矿 | 长按 `` ` ``（反引号） | FTB Ultimine |
| 鼠标批量搬运 | 无快捷键，用滚轮 / 右键拖动 | Mouse Tweaks |
| 打开任务书 | 使用任务书物品，或到「选项 → 控制」里查 FTB Quests 的快捷键 | FTB Quests |
| 查看方块信息 | 直接把准星指向方块 | Jade |

按键都可以在「选项 → 控制」里改。想精确知道自己装的模组占用了哪些键位，用 **Controlling**（内置）搜索模组名即可；`jecharacters` 让搜索支持拼音。

## 5. 开局资源提示

- 聊天栏输入 **`新手大礼包`** 可以领一次开局物资（1 钻石 + 2 铁锭）。重复领取会被作者送上天。😄
- 想快速回收硬币 / 换虚拟币，用**时钟**右键：普通右键兑换背包里所有硬币，Shift + 右键容器可以把箱子里的硬币一次性兑换。
