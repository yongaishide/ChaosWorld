# 核心系统

这几套系统贯穿整个整合包，理解了它们，任务线就不会走偏。

## 1. AE2 与频道系统

AE2 是本整合包真正的主线，配套模组有十几个：`appliedenergistics2`、`AdvancedAE`、`ExtendedAE`、`extendedae_plus`、`ae2lt`、`ae2cs`、`ae2omnicells`、`ae2wtlib`、`ae2utility`、`ae2jeiintegration`、`applied_extended_crafting`、`appliedpneumatics`、`AppliedFlux`、`mekenergistics`、`MekanismExtras`、`merequester`、`neoecoae`、`data_energistics`、`PackagedAuto`。

### 频道

任务书对频道的说明（原文要点）：

> 许多网络元件都需要频道才能运转，如终端、驱动器、ME 接口等。一旦缺少频道，那么这个设备就不工作了。**如果没有 ME 控制器而使用了超过 8 个频道，则整个网络直接瘫痪**，只剩能量交互。

整合包把「频道数量」做成了**任务奖励**，这也是本包最特别的一点：

| 奖励 | 效果 |
| --- | --- |
| 正常频道 | 恢复默认频道配置 |
| 2 倍频道 / 3 倍频道 / 4 倍频道 | 成倍提升网络可用频道 |
| 无限频道 | 解除频道限制 |

拿到奖励后可以在任务书里随时切换，等于用任务进度换网络规模。前期先用默认值 + 控制器顶着，后期直接上无限频道。

### 值得记住的两个东西

- **装配矩阵**（ExtendedAE）：近似等效于大量 ME 样板供应器 + 分子装配室组成的自动合成装置，是中期自动化合成的主力。它的墙壁 / 玻璃 / 框架都有自定义中文 tooltip。
- **全能单元**（`ae2omnicells`）：`omni_cell` 系列，普通查看只显示提示，**按住 Shift 才能看到具体字节与类型数量**（整合包自带 tooltip 说明）。

## 2. 金币与商店

整合包用 **coinsje** 的硬币作为实体货币，并在 KubeJS 里把它们接进了 **ViScriptShop** 的虚拟货币系统（单位显示为 `C`）。

### 汇率

| 硬币 | 价值（C） | 硬币堆（Pile） | 价值（C） |
| --- | --- | --- | --- |
| 铜币 | 1 | 铜币堆 | 9 |
| 铁币 | 9 | 铁币堆 | 81 |
| 金币 | 81 | 金币堆 | 729 |
| 钻石币 | 729 | 钻石币堆 | 6561 |
| 绿宝石币 | 6561 | 绿宝石币堆 | 59049 |
| 下界合金币 | 59049 | 下界合金币堆 | 531441 |

每级是前一级的 **9 倍**。

### 怎么兑换

拿一个**时钟（`minecraft:clock`）**：

| 操作 | 效果 |
| --- | --- |
| 手持时钟，普通右键 | 把背包里**所有**硬币一次性兑换成虚拟币 |
| 手持硬币，普通右键 | 只兑换手上这一格的硬币 |
| 手持时钟，**Shift + 右键容器** | 把容器（箱子、机器等）里的硬币全部兑换 |
| 潜行状态下的硬币右键 | 不触发兑换，方便你正常摆放/使用物品 |

兑换时有音效和粒子反馈，状态栏会播放余额数字。

## 3. 等价交换（ProjectE）

`ProjectE` + `projectexpansion` + `ProjectE_Integration` 三件套都在包里，属于后期的**资源自由**路线：把冗余资源换算成 EMC，再用 EMC 换需要的材料。

注意：整合包改写了大量配方，ProjectE 能换到的东西**取决于物品的 EMC 值**，不要指望它能跳过主线材料（尤其是 `chaosworld_core` 的自定义材料）。

## 4. 压缩方块与材料金字塔

- **All The Compressed**：把资源压成 1x ~ 9x 的压缩方块，方便囤积与自动化。
- **All The Ores / All The Modium**：统一矿物与高阶材料。
- **`chaosworld_core`**：整合包自定义模组，提供专属材料与机器（例如玄彩锭、龙钢、龙魂锻造、自定义多方块高炉），是主线后期绕不开的东西。

奖励章「材料金字塔」共 91 个任务，专门用来查**每种材料的来路**。

## 5. 无尽与终局

- **Re-Avaritia**：无尽贪婪，工作台转换配方由 KubeJS 自动生成。
- **Extended Crafting**：拓展合成，提供合成矩阵 / 通量合成（Flux Crafter）等大型合成方式。
- **Sophisticated Storage / Backpacks**：无尽升级（Infinity Upgrade）是「新未来」章节的图标物品。
- **`staaaaaaaaaaaack`**：堆叠上限提升，后期箱子里动辄上万。

## 6. 多方块与自定义机械

整合包里有相当多自定义或多方块内容，遇到"摆不出来"的多方块，先确认三件事：**结构尺寸、外壳材质、接口数量**。

| 内容 | 提示 |
| --- | --- |
| 通用机械压力室 | 中空正方体，棱长 3/4/5，主体用压力室墙壁或玻璃，至少 1 个阀门，建议加接口 |
| 冶炼炉（alloy_smelter） | 1 级红砖 / 2 级磨制黑石砖 / 3 级末地石砖，高级炉兼容低级配方且更快 |
| 装配线 | 装配平台 + 装配钻头 + 装配激光 + 装配台交互设备（输入/输出）+ 装配台，交互设备会自动从周围箱子取料、放回产物 |
| MMCR / Multiblocked2 | 整合包自定义多方块机械（KubeJS 高炉等），JEI 里可查多方块预览 |
| 无线充能网络 | 每个网络最多 1 个控制器；网络名 / 颜色 / 是否公开可在 GUI 里设置，仅用于无线充能 |

## 7. 便利功能

- **死亡不掉落**：开局任务即可领取，之后也能在任务奖励里切换。
- **FTB Ultimine**：连锁挖矿。
- **FTB Chunks**：认领区块、小地图式区块管理。
- **FTB Essentials**：`/home`、`/tpa`、`/back` 等指令（具体权限以服务器 / 单人设置里的配置为准）。
- **Waystones**：传送石碑，跨维度赶路。
- **Sophisticated Backpacks**：背包 + 升级模块。
